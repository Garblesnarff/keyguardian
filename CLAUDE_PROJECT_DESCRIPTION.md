# API Key Wallet (KeyGuardian) - Claude Project Description

## Project Overview
API Key Wallet is a Flask-based web application for secure API key management that I'm transforming into both a SaaS API service and the world's first MCP (Model Context Protocol) native key manager. Located at `/Users/rob/Claude/workspaces/keyguardian/`.

## Current State
- **Tech Stack**: Python Flask, PostgreSQL, SQLAlchemy, Fernet encryption
- **Features**: User auth, encrypted key storage, categories, web UI
- **Status**: Working prototype ready for API/MCP transformation

## Strategic Vision
Transform this simple key manager into a profitable SaaS targeting the $32.77B API management market (growing 25% CAGR) by being:
1. **Simplest** - 5-minute setup vs hours for competitors
2. **MCP Pioneer** - First key manager with native AI assistant integration
3. **Developer-First** - Fair pricing (not per-user), open source core

## Business Model
- **Freemium SaaS**: Free (5 keys) → $9/mo → $29/mo → $99/mo
- **Target**: Solo devs, small teams, AI/ML engineers
- **Goal**: $1M-$2M ARR by Year 3 (conservative)
